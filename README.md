# 📦 Exercício CSS - Modelo de Caixas (Box Model)

Este repositório contém um exercício prático da faculdade focado no estudo do *Box Model* (modelo de caixas) e propriedades de estilização com CSS.

## 📌 Sobre o Projeto

O exercício explora a aplicação visual de elementos estruturais e caixas em uma página web, abordando:
- **Reset básico e Box-Sizing:** Padronização de margens e preenchimentos com `box-sizing: border-box`.
- **Estilização do Corpo (`body`):** Limitação de largura máxima, centralização automática (`margin: auto`) e uso de bordas tracejadas.
- **Bordas e Espaçamentos:** Aplicação de diferentes tipos de bordas (`dashed`, `dotted`, `double`) e recuos em títulos (`h1`, `h2`, `h3`) e parágrafos (`p`).
- **Uso de Classes:** Criação de um bloco personalizado (`.classediv`) para destacar uma seção específica do conteúdo.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação do texto explicativo e divisão por blocos/classes (`div`).
- **CSS3**: Estilização de margens, *padding*, bordas, cores e layout centralizado.
