# 🎨 Exercício CSS - Múltiplos Estilos e Layouts

Este repositório contém um exercício de CSS desenvolvido para a faculdade, focado em praticar a alternância de folhas de estilo 
e o uso de imagens de fundo.

## 📌 Sobre o Projeto

O projeto é dividido em duas partes práticas:
1. **Múltiplos Estilos:** Mostra como a mesma página (`index.html`) muda de visual apenas trocando o arquivo CSS vinculado no `<head>` (`style-02-1.css`, `style-02-2.css`, etc.).
2. **Exercício 3 (`Exercicio-3.CSS`):** Uma página adicional que aplica estilos com imagens de fundo (texturas de tijolos e marcadores).

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação das páginas.
- **CSS3**: Estilização, cores e imagens de fundo (*background-image*).
