# 🎓 Site Institucional - Escola de Informática (Bootstrap)

Este repositório contém uma atividade prática desenvolvida para a faculdade, focada na criação de um site responsivo para uma escola de informática utilizando **Bootstrap** com ficheiros locais.

## 📌 Sobre o Projeto

O site simula uma página institucional voltada para a oferta de cursos de tecnologia, contendo:
- **Páginas Múltiplas:** Estrutura organizada com página inicial (`index.html`), secção de cursos (`cursos.html`) e formulário de contacto (`contato.html`).
- **Oferta Formativa:** Cursos voltados para a área de TI (como *Python Introdutório*, *Banco de Dados SQL*, *Power BI Avançado* e *Redes & Nuvem*), detalhando durações e valores.
- **Bootstrap Local:** Utilização da framework CSS/JS descarregada diretamente no projeto para estilização e responsividade offline.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação dos documentos e páginas.
- **Bootstrap (Local)**: Framework CSS e JS para o design responsivo, grelhas e componentes visuais.
