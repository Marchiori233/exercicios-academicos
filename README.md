# 🛒 E-commerce de Eletrónicos (Trabalho Prático)

Este repositório contém o trabalho prático final (T2) desenvolvido para a universidade. Trata-se de uma simulação de uma loja virtual (*e-commerce*) dedicada à venda de produtos eletrónicos e tecnologia.

## 📌 Sobre o Projeto

O projeto consiste num website multi-páginas interligado com navegação interna funcional, contemplando:
- **Catálogo de Produtos:** Apresentação geral e páginas dedicadas para 5 produtos distintos (com galerias de imagens detalhadas para dispositivos como iPhone, PlayStation 5, auscultadores Sony, Smart TV e Apple Watch/AirPods).
- **Navegação Institucional:** Páginas de apresentação (`sobre.html`, `projeto.html`) e secção de notícias/atualizações (`noticias.html`). Na página `projeto.html`, encontram-se detalhadas as informações sobre o desenvolvimento e a dinâmica da equipe.
- **Interação com o Utilizador:** Formulários de registo/cadastro de utilizadores (`cadastro.html`), páginas de contacto (`contato.html`) e confirmação de mensagens.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação e marcação semântica de todas as páginas da loja.
- **CSS3**: Estilização visual, organização do catálogo e formatação dos elementos.
- **Bootstrap (5.3.3)**: Framework CSS utilizada de forma pontual na página de cadastro (`cadastro.html`).
