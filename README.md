# 👗 Projeto Fashion (Exercício Acadêmico)

Este repositório contém um projeto prático desenvolvido para a faculdade, focado na criação de uma página web estática com a temática de moda (*Fast Fashion*).

## 📌 Sobre o Projeto

O site simula um portfólio ou página de apresentação de tendências de moda, composto por:
- **Cabeçalho (*Header*):** Logótipo estilizado e menu de navegação decorativo (*Portfolio*, *About Us*, *Contact*).
- **Banner de Destaque:** Imagem principal de introdução com o título e texto descritivo.
- **Grelha de Produtos/Modelos:** Seção em destaque com três itens (*Vest Romasa*, *Jacket Fima* e *Jacket Black Kira*) acompanhados de descrições.
- **Rodapé com Contactos e Mapa:** Seção final contendo números de telefone para contacto e incorporação de mapa geográfico.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Marcação estrutural do conteúdo, textos e secções.
- **CSS3**: Estilização visual, cores de fundo, tipografia e organização dos elementos da página.
