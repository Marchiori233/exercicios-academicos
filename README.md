# 🎨 Exercício CSS

Este repositório contém um exercício de introdução ao CSS desenvolvido para a faculdade, focado em **CSS (Cascading Style Sheets)** 
e na aplicação de estilos visuais a uma página web.

## 📌 Sobre o Projeto

O exercício apresenta conceitos fundamentais de estilização web, abordando:
- **Separação de responsabilidades:** Uso de HTML para o conteúdo e CSS externo para a formatação visual.
- **Seletores Básicos:** Estilização de elementos como cabeçalhos (`h1`, `h2`, `h3`) e do corpo da página (`body`).
- **Propriedades Visuais:** Modificação de cores de texto, cores de fundo (*background-color*) e organização de parágrafos explicativos.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação do texto informativo.
- **CSS3 (Folha de Estilos Externa - `style.css`):** Aplicação de regras visuais e cores ao documento.
