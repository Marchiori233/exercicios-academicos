Exercício acadêmico em HTML

-Descrição
Site simples desenvolvido em HTML com o intuito de treinamento e prática de técnicas
de desenvolvimento web. O projeto utiliza diversas tags HTML para estruturar
uma página inicial e três páginas de conteúdo semelhante, exibindo conteúdo estruturado
e imagens.

-Tecnologias Utilizadas
HTML5

-Como Visualizar
Abra o site em um navegador web.
