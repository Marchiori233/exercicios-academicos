Relatório de Desenvolvimento do Projeto

1. Estrutura do Grupo e Adaptação

Inicialmente, o grupo era composto por três integrantes: Breno Marchiori, Gabriel **** e Lucas ****. No entanto, devido a conflitos de horários, o integrante Gabriel **** não pôde dar continuidade à disciplina neste período. Diante disso, os integrantes Breno e Lucas redistribuíram as tarefas entre si para garantir a execução completa do projeto.

2. Planejamento e Design de Layout

O processo de desenvolvimento iniciou-se com a etapa de design de interface (UI). Utilizamos a plataforma Figma para projetar o layout visual do site, que consiste em uma loja virtual voltada para o segmento de eletrônicos (TechZone).

Embora o objetivo inicial fosse reproduzir fielmente o protótipo do Figma, a codificação individual de cada página gerou, em um primeiro momento, divergências visuais. Foram necessários ajustes posteriores nos códigos para unificar a identidade visual. Ainda assim, persistem diferenças sutis, como os cabeçalhos e rodapés de algumas páginas.

3. Divisão do Trabalho e Cronograma

O cronograma de desenvolvimento do site foi estruturado originalmente em três etapas principais, sendo a última fase redistribuída entre os dois integrantes restantes:

  • Parte 1 (Base do Projeto): Criação das páginas index.html, home.html
  • Parte 2 (E-commerce): Desenvolvimento do ecossistema de produtos (produtos.html e as páginas individuais de produto1.html a produto5.html).
  • Parte 3 (Formulários e Conteúdo): Implementação das páginas noticias.html, cadastro.html, contato.html e projeto.html.

4. Expansão do Escopo e Inclusão da Página "Sobre Nós"

Durante a revisão dos requisitos do projeto nas semanas finais, identificamos a necessidade de incluir uma página adicional de autoria própria. Optamos pela criação da página "Sobre Nós" (sobre.html), um elemento comum em e-commerces reais. Esta página foi desenvolvida para apresentar a história, a missão, a localização física (com integração ao Google Maps) e os valores institucionais da empresa fictícia do nosso trabalho.

5. Desafios de Aprendizado e Metodologia de Desenvolvimento

O desenvolvimento exigiu pausas estratégicas ao longo do cronograma. Como alguns recursos visuais demandavam conhecimentos além do que dominávamos no momento, foi necessário pausar o código para aprofundar o estudo dos conceitos ministrados em sala de aula, especialmente no que tange às propriedades um pouco mais avançadas do CSS.

Como base teórica e técnica, utilizamos principalmente os materiais in formato de slides disponibilizados no portal do Professor.

6. Responsividade e Abordagem Tecnológica (CSS Nativo vs. Bootstrap)

A responsividade do site apresenta variações entre as páginas. Algumas se adaptam bem a smartphones, tablets e monitores de grande porte através do uso de CSS. Em outras páginas, a adaptação para telas menores ficou mais limitada.

Nota sobre o uso de Frameworks: O projeto foi construído majoritariamente em CSS puro e nativo. No entanto, o framework Bootstrap foi utilizado exclusivamente na página de cadastro (cadastro.html) para a estruturação do formulário. A integração do framework foi feita de forma direta por meio de link externo (CDN), sem a necessidade de baixar os arquivos para o projeto local. Nas demais páginas, optou-se por manter o desenvolvimento nativo, já que a estrutura principal já estava concluída quando obtivemos o domínio teórico sobre o Bootstrap em sala de aula.

7. Processo de Homologação e Testes

Para garantir a qualidade da interface, o processo de testes seguiu as diretrizes recomendadas nas videoaulas do Professor sobre inspeção de código. Os testes consistiram em:

  • Utilização da ferramenta de inspeção do navegador Google Chrome, via tecla F12, para simulações.
  • Testes de acessibilidade e quebra de layout aplicando níveis de zoom extremos (redução para 60% e ampliação para 140%).
  • Navegação exaustiva para validação de fluxos e links.

8. Conclusão e Considerações Finais

O prazo de entrega mostrou-se altamente desafiador, especialmente quando somado à redução de um integrante no grupo e ao fluxo de atividades de outras disciplinas. Contudo, consideramos o resultado bastante proveitoso. Apesar de não termos atingido a fidelidade absoluta em relação ao desenho inicial do Figma, o projeto final entregou uma estrutura de HTML e CSS próxima à realidade de uma plataforma de vendas digitais profissional. Com um prazo mais extenso, teríamos margem para refinamentos ainda mais precisos na consistência visual do código.

Objetivo do Site

O site TechZone foi desenvolvido como projeto acadêmico com o objetivo de criar uma loja virtual de eletrônicos e tecnologia, apresentando produtos de forma organizada e profissional. O projeto busca aplicar conhecimentos de HTML e CSS na construção de páginas web responsivas e atrativas.

A plataforma oferece informações detalhadas sobre produtos eletrônicos, permitindo aos usuários conhecer especificações técnicas, preços e condições de pagamento de forma clara e acessível.

Público-Alvo

O site TechZone é destinado a:

  • Entusiastas de tecnologia que buscam produtos eletrônicos de qualidade
  • Consumidores interessados em smartphones, notebooks, smartwatches e acessórios
  • Pessoas que valorizam informações detalhadas antes de realizar uma compra
  • Usuários que preferem navegar em sites com design moderno e responsivo
